## About Me

Informatics Engineering student at **Universitas Nusa Putra**, Sukabumi, graduating 2027.
I build backends and APIs with **Laravel** and **FastAPI**, and wire in AI where it makes sense: RAG pipelines, YOLO-based detection, production chatbots. Side interest: Blender and 3D on the web.

- Informatics Engineering @ Universitas Nusa Putra (2023 – 2027)
- Fullstack Developer Intern @ PT Akebono Brake Astra Indonesia (2026)
- Currently building: ChatbotSunda (RAG chatbot) and an interactive 3D portfolio
- Learning: PostgreSQL full-text search, FastAPI lifespan patterns, production deployment
- Based in Sukabumi, Indonesia
